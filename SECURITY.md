# Security

Please do not open a public issue for a vulnerability, leaked credential, or private server detail.

Use GitHub's private vulnerability reporting for this repository instead. Include the affected version, a clear reproduction, and the impact you observed. Remove API keys, passwords, tokens, hostnames, and personal media details from logs before attaching them.

Community maintainers will confirm the report, work on a fix, and coordinate disclosure when one is needed. There is no guaranteed response time, but security reports take priority over ordinary bug reports.

Only the latest Nullfin release and the main branch receive security fixes.
